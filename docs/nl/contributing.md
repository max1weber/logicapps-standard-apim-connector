# Bijdragen

[English](../en/contributing.md)

Breng verbeteringen graag terug via pull requests. Link het issue, beschrijf zichtbaar gedrag en voeg relevante verificatie toe. Organiseer wijzigingen als vertical slices. Werk beide documentatietalen bij. Publiceer geen organisatiecontracten of credentials. Bewijs designergedrag met de echte Standard-designer. Lees vóór bijdragen de huidige LICENSE; de licentiekeuze staat nog open.
