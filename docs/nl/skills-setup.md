[English](../en/skills-setup.md)

Ingesteld op 2026-10-14 met setup-matt-pocock-skills. GitHub Issues is de tracker. De vijf standaard triage-labels bestaan. AGENTS.md verwijst naar canonieke tweetalige documenten onder docs/agents. Domeinindeling: één context met GLOSSARY.md en docs/adr, die ontstaan zodra nodig. Geen globale agentinstallatie vereist. Heropen het project om projectspecifieke skills te ontdekken.

Lees [issue-tracker](../agents/issue-tracker.md), [labels](../agents/triage-labels.md) en [domeinregels](../agents/domain.md). Onder andere to-spec, to-tickets, triage, wayfinder en domain-modeling gebruiken deze afspraken. Wijzig bestanden rechtstreeks voor andere conventies; herhaal setup bij wijziging van tracker/indeling.
