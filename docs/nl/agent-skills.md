27 ongewijzigde Matt Pocock engineering/productivity-skills staan projectspecifiek onder .agents/skills. Bron: https://github.com/mattpocock/skills op 49dd158d1076134a641b33efb035946536778336. Referenties, scripts en agentmetadata zijn inbegrepen. De oorspronkelijke MIT-licentie staat in .agents/skills/LICENSE.mattpocock. Dit zijn instructies van derden voor ontwikkelagents, geen connector-runtimecode.

Een agent met ondersteuning voor projectspecifieke .agents/skills kan ze na heropenen ontdekken. Dit installeert geen globale plugin en activeert ze niet in ChatGPT. Installeer dezelfde plugin niet daarnaast tenzij dubbele skills gewenst zijn. De repositorysetup is afgerond: GitHub Issues, standaard triage-labels en één domeincontext zijn ingesteld via AGENTS.md en docs/agents. Zie [setup](skills-setup.md). Documentatie hoort in overeenkomende docs/en- en docs/nl-bestanden.

Review bij updates upstreamwijzigingen, vervang skills en ondersteunende bestanden samen, behoud de licentie, noteer de nieuwe commit in THIRD_PARTY.md en commit via een pull request. Er is tijdens installatie geen upstreamscript uitgevoerd.
