# Logic Apps Standard APIM Connector

[ Nederlands ](README.nl.md)

Experimental preview: C# discovery, a registered Standard adapter and bound API execution build in CI. Azure Portal authoring and production developer authorisation are still unproven.

Live design-time discovery: APIM connection → API → version → operation → typed inputs/outputs. Runtime uses environment-specific gateway settings. The exact designer experience must first be proven in a PoC.
